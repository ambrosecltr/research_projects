# GENOME code map

| Path | Responsibility |
|---|---|
| `genome/mgp/` | Deterministic MGP schema, serializer, validation, and runtime. |
| `genome/adapters/gpt_neox.py` | Strict PolyPythia GPT-NeoX native/canonical conversion and model assembly. |
| `genome/polypythia/catalog.py` | Round One ten-life split and checkpoint policy. |
| `genome/polypythia/hub.py` | Immutable Hugging Face source planning, endpoint download, and hidden reveal control. |
| `genome/polypythia/evidence.py` | Endpoint-free compiler evidence from W0 and model-life descriptions. |
| `genome/polypythia/prepare.py` | Canonical W0/WT life artifacts and sealed hidden corpus. |
| `genome/polypythia/lives.py` | Strict canonical model-life loaders. |
| `genome/polypythia/evaluate.py` | Decoder audit, hidden runtime, Wikitext comparison, and pinned LM Evaluation Harness suite. |
| `genome/polypythia/cli.py` | Complete Round One command group. |
| `genome/neural/block_decoder.py` | Shared role-conditioned Neural Genome Decoder. |
| `genome/neural/multilife_decoder.py` | Joint multi-life decoder training and frozen development-code fitting. |
| `genome/neural/compiler.py` | Fixed-layout probabilistic genome-code predictor. |
| `genome/neural/predictive_compiler.py` | Compiler training through the frozen decoder and sealed hidden prediction. |
| `configs/polypythia_14m_round1.yaml` | Sealed Round One source, split, recipe, and training configuration. |
| `configs/lm_eval_round1/` | Pinned zero-shot task definitions and dataset revisions. |
| `POLYPYTHIA_ROUND1.md` | Exact local and RunPod execution order. |
| `POLYPYTHIA_ROUND1_RESULTS.md` | Completed decoder, Compiler, hidden, and task-suite results. |
| `genome/adapters/poetry50m.py` | Legacy 50M Track 1 G0 adapter. |
| `configs/poetry50m_track1.example.yaml` | Legacy 50M Track 1 example, not the new 8M full-life record. |
| `tests/test_polypythia_round1.py` | Round One split, compatibility, leakage, learned-path, and source-pin regressions. |
